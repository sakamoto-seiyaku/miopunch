# Triage Labels

The five canonical state roles use the same names in Plane project `MIOPUNCH`:

| Role | Plane label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting on reporter information |
| `ready-for-agent` | `ready-for-agent` | Ready for agent work |
| `ready-for-human` | `ready-for-human` | Requires human action |
| `wontfix` | `wontfix` | Will not be actioned |

Use this mapping when a skill refers to a triage role. These labels are
project-specific; do not reuse IDs from another Plane project.
