# Domain Docs

This is a single-context repository. Start with the root
[README](../../README.md) and [CONTEXT](../../CONTEXT.md), then read the
[product direction draft](../notes/2026-09-27-product-mainline-draft.md),
[scenario walkthrough](../notes/2026-09-28-network-scenario-walkthrough.md),
and any relevant [ADRs](../adr/).

The September 2026 notes distinguish confirmed behavior from open questions.
Source research, implementation maps, and experiment suggestions are evidence,
not product decisions. Use the vocabulary in `CONTEXT.md`; surface conflicts
with accepted ADRs instead of silently changing them.

The Go/Android code, former decisions, OpenSpec files, and old agent prompts
under `archive/legacy-go-openspec-2026-09-28/` are historical. Consult them
when investigating lineage, not as implementation constraints. Work state
belongs to Plane, not repository docs.
