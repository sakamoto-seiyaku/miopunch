# 共享 Vue 界面，Tauri 安装版外壳与 Rust 节点

2026-10-20，用户确认采用 Vue 3 + TypeScript + Vite 共享界面，Tauri 2 作为安装版外壳，Rust 承担节点与业务逻辑。选择依据是复用页面和操作流程、降低长期维护成本，并满足既定功能与易用性要求；不追求界面全部使用 Rust，也不为理论性能差异持续更换框架。

安装版接入原生 Rust 节点，普通浏览器／PWA 接入自己的 Rust/WASM 节点，保留独立身份与成员资格；Linux 无界面宿主直接使用原生节点。各平台按实际需要提供系统能力与生命周期适配，共享界面不要求所有系统调用或构建产物相同。适配代码是正常工程组成，复用与功能要求是验收依据。

内网 Web 服务继续由所选节点访问其可达目标，并在 miopunch 应用内打开。远端网页与节点管理权限的隔离由内部实现处理；具体页面容器、模块接口、组件库、依赖版本及性能预算仍待确定。

本决定采纳技术栈与职责方向，不表示五个业务模块、Android 后台宿主或网页兼容性已经通过运行验证，也不自动启动实现。依据见[讨论记录](../notes/2026-10-03-shared-web-client-ui-direction.md)与[适配研究](../notes/2026-10-20-shared-ui-stack-fit-research.md)。

2026-10-29，MIOPUNCH-121 实施期间，用户进一步确认 Android 手机重启后恢复联网**默认开启，可在设置关闭**。这取代此前默认开关未定的状态；实际系统启动、应用 Context、原生节点所有权和持久重开仍须在真实 APK 验证，不能由开关存在推定通过。
