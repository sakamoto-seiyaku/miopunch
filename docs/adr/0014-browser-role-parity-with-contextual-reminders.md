# 浏览器与 PWA 的管理权限平等，平台差异通过提醒表达

2026-10-20，用户明确当前阶段的取舍。用户的长期使用环境可能是浏览器或 PWA；管理员资格、创世权限使用和创世凭证保管沿用与安装版相同的授权规则，不因客户端是浏览器而增加特别限制。此前“浏览器默认仅临时使用创世凭证、长期保管另加限制”的建议不采用；用户按统一流程决定哪些设备保管凭证。

存储清理、页面暂停、实际在线状态及页面代码信任等环境差异，通过相关操作中的适度提醒表达，提醒本身不成为浏览器专属的审批或阻断门槛。所有客户端仍遵守既有身份、成员授权、创世签名、用户确认和资源许可规则；[ADR 0013](0013-genesis-recovery-card-without-mandatory-password.md) 的首次保存恢复卡要求继续统一适用。具体提醒时机与文案尚待设计。

权限资格平等不代表已经交付完全相同的运行能力：浏览器长期凭证保护、创建／恢复与界面接线仍须补齐；页面暂停后也不能宣称仍在接收申请或核销邀请码。本决定记录当前产品策略，不启动实现。讨论与能力核对见[浏览器管理与凭证保管](../notes/2026-10-03-shared-web-client-ui-direction.md)。
