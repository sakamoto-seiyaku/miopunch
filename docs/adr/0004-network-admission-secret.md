# 用共同准入秘密限制恢复引导

2026-09-28，已接受。面向个人与小型网络，使用独立于节点身份和创世凭证的共同准入秘密限制引导交流，再由成员授权状态决定正常同步及业务权限；不向未通过准入秘密验证的任意端点开放管理历史，也不设计专用最小证明包。

为减少密钥管理与离线恢复复杂度，成员移除不强制轮换；接受旧秘密持有者以新身份取得引导信息，以及未知撤销的传播窗口。轮换需要创世提权，保留成员须确认保存新秘密，未确认者等待或明确剔除；轮换期间暂停入网处理与入网秘密交付。秘密泄露时可选择移除并轮换。

完整决议、首次入网交付与新 code 恢复边界以 Plane 的[明确未知合法成员恢复所需的发现与证明交换](http://192.168.4.22:2080/work/projects/aa58cd82-2afc-404b-a097-58ef553c7ca4/issues/47998080-f6b1-4361-95b7-5d490bfa8503)决议评论为准。成熟证明协议、旁信道保护、具体发现入口和库接入仍待选型与验证；本决定不表示共享秘密可以解密其他端点的私密会话。
