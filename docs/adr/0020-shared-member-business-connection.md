# 同一对成员设备的业务共用 QUIC 连接

2026-11-19，同一网络内，两台已准入的成员设备按需建立一条共享业务连接。首次业务需要时建连，后续文件、终端等业务默认在已有连接上开独立的 QUIC 流。iroh 为共享连接做打洞、路径验证和换路。原连接从中继切到直连时，其上正在传输的文件和终端会话一起沿新路径继续。

同一端的多个业务同时联系同一成员时，共用一次进行中的建连。两端同时向对方首拨时，允许并行握手；双方在交付第一条业务流前确定同一条共享连接。已有可用的共享连接时，后续业务直接在其上开流。

单向首拨通过已有握手和准入交换交付，额外的仲裁往返次数为零。只有两端互拨、两条合格候选连接确实重叠时才按已认证节点 ID 的字节顺序裁决，选择较小 ID 一端发起的连接。双方选定同一连接后才对业务开放流。Replica 同步、访客、入网及恢复等专用协议继续使用各自的准入范围。

接收端按流识别业务并检查当前服务权限。撤销某项服务权限时，结束该对端受影响的服务流，并拒绝后续未获授权的请求；同一连接上其他获准业务可以继续。成员资格失效时，关闭该成员业务连接。受限联系入口仍按 [ADR 0005](0005-side-channel-control-bootstrap.md) 承载握手和控制，成员业务连接须经准入并具备获准的数据路径才能交付。

共享连接的所有者负责持有和关闭连接。服务只持有本服务的流、对端上下文和取消能力。最后一项业务释放后，共享连接进入本节点在该私有网络的待命名额，保守档默认 1 个，积极档默认 4 个。名额按已准入对端计数，多条流共用一条连接。新近结束业务的连接优先保留，满额时先释放只用于检查的空闲连接，再按最后一次业务释放时间回收。周期 ping 在原连接开维护流；满额时对新对端的单次检查可以收完回复，随后释放临时连接。检查与打洞沿用后台优先级。节点退出、撤权或传输断开时清理连接。

2026-11-20，根据双 NAT 现场对照修订。探索间隔只安排同步、探索和后台联系。待命中缺少合格直连时，融合端点在原连接上按节点额度尝试并重试，直连恢复后结束增强探测。单轮受联系期限、双方剩余预算和取消信号约束。增强 UDP 冷却和路径重试基准按节点独立配置。

iroh 已按对端传播普通路径线索，每条连接仍须验证自己的路径。当前额外成本主要来自按业务拨不同连接、改善时另拨控制连接，以及胜出 socket 绑定特定原连接。共享业务连接能将这些成本摊给各条流。代价是连接级故障同时影响其上所有流，同一慢路径上的大流、交互请求和建路控制也会竞争发送机会。用持续写入的大流、小请求和受保护的换路交换实测各自的原期限，载荷可选专用测试流。[iroh 路径传播](../../vendor/iroh/src/socket/remote_map/remote_state.rs#L1573) · [文件拨号](../../src/native_file_transfer.rs#L441) · [终端拨号](../../src/native_terminal.rs#L524)
