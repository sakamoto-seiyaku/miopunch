# 经可替换旁信道复用端点安全握手

2026-09-28，已接受的设计方向。允许产品支持的 MQTT、IRC 等消息旁信道递送受限的 iroh 握手和连接控制报文，先建立端点安全会话，再协调直连或获准中继；复用 iroh 的身份与会话保护，减少额外密码握手和身份绑定的维护。

旁信道的业务承载资格必须受限，成员准入仍独立检查；临时投递标识不代替加密，接受必要元数据可见。具体准入持有证明、载体适配和同一连接路径转换仍需验证，复用此机制不要求使用官方服务器。完整决议以 Plane 的[明确入网前后私密信令的信任材料与保护边界](http://192.168.4.22:2080/work/projects/aa58cd82-2afc-404b-a097-58ef553c7ca4/issues/e843bdf9-60a0-4b6f-a27e-a2c7359cf563) Resolution 为准，依据与验证边界见[机制核查](../notes/2026-09-28-private-signaling-mechanism-research.md)。
