# 所有 precode 绑定唯一核销节点

2026-09-28，已接受。为遵循 KISS、统一兑换和权限处理，所有 precode（包括仅限时间的码）都绑定唯一核销节点，单码撤销由该节点管理；接受该节点不可用时不能新兑换的代价，放弃本轮多节点核销及跨管理员单码撤销。管理员资格撤销使其旧码失效，恢复资格不复活旧码；已签发成员授权独立存在。

完整决议及故障恢复边界以 Plane 的[明确 precode 指定核销与故障恢复规则](http://192.168.4.22:2080/work/projects/aa58cd82-2afc-404b-a097-58ef553c7ca4/issues/0f43545c-b931-4936-aa6d-3ee57c9f0071)决议评论为准；本决议不选择持久化协议或密码机制。
